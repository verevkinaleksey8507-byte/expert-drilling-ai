# Excel Application

`ExpertSupervisor.xlsm` is the Excel application entry point for Expert Drilling AI.

Version `0.2.0` contains one worksheet named `IWCF Kill Sheet` with a two-page Russian-language layout for a vertical well with a surface BOP stack.

The workbook currently contains:

- well, formation-strength, pump and circulation-data sections;
- drill-string and annular-volume tables;
- kick-data and future calculated-value fields;
- a pressure-reduction schedule;
- an operational plan and approval section;
- semantic field colors: yellow for input and grey for future calculated output.

Version `0.2.0` intentionally contains no formulas, calculations, VBA or automation.
